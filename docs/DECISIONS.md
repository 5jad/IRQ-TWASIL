# Architectural & Design Decisions (DECISIONS.md)

| ID | Date | Subject | Decision | Rationale |
|---|---|---|---|---|
| DEC-001 | 2026-11-11 | Self-Hosted Fonts & RTL | Self-host `@fontsource/cairo` (400, 600, 700) and `@fontsource/reem-kufi` (600, 700) with `dir="rtl"` and `lang="ar"` on `<html>`. Zero runtime requests to external font CDNs. | Ensures complete offline reliability, privacy, and fast first-contentful paint on mobile connections across Iraqi governorates. |
| DEC-002 | 2026-11-11 | Themes, Tokens & Persistence | 4 full themes (Light/رمال بغداد, Dark/كحّلة, Calm/هادئ, High-Contrast/تباين عالٍ) mapped to CSS variables. Stored safely under `tw.prefs.v1` and `tw.canvas.v1` with try/catch fallback, inline anti-flash script, and `system` theme auto-matching `prefers-color-scheme`. | Ensures zero hard-coded hex colors in components, eliminates theme flash on refresh, and survives blocked storage without errors. |
| DEC-003 | 2026-11-11 | Accents & WCAG Contrast | 8 per-user accent colors (`teal`, `copper`, `indigo`, `green`, `rose`, `violet`, `slate`, `gold`) paired with verified foreground tokens (`--accent-fg`, `--primary-fg`, `--danger-fg`, `--border-strong`). | Satisfies WCAG AA contrast (minimum 4.5:1 text, 3:1 controls) across all theme combinations. |
| DEC-004 | 2026-11-11 | Floating BottomBar | 64px floating glass pill with 5 equal slots (Home, Reels, Chat, Market, Profile). All tabs share identical slot width and 26px stroke styling. Long-press on chat tab (500 ms) opens recent chats sheet via pointer events. Handedness uses physical side docking (right-handed 16px from physical right, left-handed 16px from physical left). | Implements normalized visual hierarchy where chat is an equal peer tab, providing comfortable one-handed reachability in RTL. |
| DEC-005 | 2026-11-11 | Profile Canvas Security | Profile Canvas uses strictly validated JSON configurations verified with Zod allowlists. Rejects unknown keys, prototype pollution, oversized payloads, and unvalidated block settings. No arbitrary HTML, CSS, or JS execution. | Conforms strictly to Master Prompt Section 14.1 security boundary. |
| DEC-006 | 2026-11-11 | Currency & Market | Fixed IQD (`د.ع`) without decimals. Agreement between buyer and seller directly without hidden fees. | Master Prompt Section 12 scope boundary. |
| DEC-007 | 2026-11-13 | Live Mode UI Preview | `/create?mode=live` provides a local camera preview, audience sheet, countdown, elapsed timer, and track cleanup on end without a WebRTC/RTMP streaming backend. | No streaming server exists yet; UI clearly marks the preview as local (`تجربة محلية، لا يوجد بث فعلي`). |
| DEC-008 | 2026-11-15 | Iraqi Phone OTP & Cookie Sessions | Passwordless 6-digit OTP challenges (`tw_otp_challenges`) + opaque hashed tokens in HttpOnly SameSite=Lax cookies (`tw_sessions`), paired with AES-256-GCM encrypted phone storage and HMAC-SHA256 blind indexes. | Eliminates password reuse risk, keeps raw phone numbers redacted in logs, and supports multi-device revocation without JWT revocation lists. |
| DEC-009 | 2026-11-15 | 3-Step Media Pipeline & Local Fallback | Media uploads follow `POST /api/media/uploads` -> `PUT` upload -> `POST /complete` with magic-byte sniffing, using S3/R2 in production and `./.data/uploads` in local development. | Prevents unverified MIME uploads and removes ephemeral `blob:` URL breakage across reloads. |
| DEC-010 | 2026-11-15 | SSE + Delta Sync & Bot Factory | Real-time chat/notifications stream over authenticated `EventSource('/api/events')` with 20s `/api/bootstrap/delta` fallback; bots use scoped token auth and `@botfactory_bot`. | Keeps infrastructure stateless-friendly on Express + PostgreSQL while delivering sub-second updates and interactive bot keyboards. |
