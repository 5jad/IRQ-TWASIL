# Design Audit & Defect Checklist (DESIGN_AUDIT.md)

| # | Item / Component | Initial Finding | Remediation Applied | Status |
|---|---|---|---|---|
| 1 | Font rendering | Fonts loaded from Google Fonts CDN at runtime | Self-hosted `@fontsource/cairo` (400, 600, 700) and `@fontsource/reem-kufi` (600, 700), preloading Arabic 400 and 700 `.woff2` files at build time; zero external font requests | Resolved |
| 2 | CSS Color Tokens | Hardcoded hex colors in component swatches, story rings, and profile presets | Moved all colors to semantic CSS variables in `src/index.css` across all 4 themes (`light`, `dark`, `calm`, `high-contrast`) and 8 `[data-accent]` presets; tokenized story rings (`--success`, `--border-strong`), profile backgrounds (`--profile-bg-*`), and status badges (`--accent-fg`, `--danger-fg`, `--warning-tint`, `--lapis`, `--gold`) | Resolved |
| 3 | Contrast Ratios & Borders | Missing `-fg` and strong boundary tokens; static contrast script could drift | Added `--accent-fg`, `--danger-fg`, `--lapis`, `--lapis-fg`, `--gold`, `--gold-fg`, `--warning-tint`, and 3:1 `--border-strong`; rewrote `scripts/check-contrast.ts` to parse `src/index.css` dynamically across all themes and 8 light/dark accents (7:1 high-contrast text) | Resolved |
| 4 | Bottom Bar Hierarchy & Handedness | Chat tab was rendered as a 52px circle and handedness used RTL `start`/`end` (flipped physically) | Unified all 5 tabs in `BottomBar.tsx` to identical 65x56 slots and 26px outline icons with active dot; used physical `right-[16px]`/`left-[16px]` docking and pointer-event 500 ms long-press | Resolved |
| 5 | Dialogs Accessibility | Dialogs lacked Escape close, focus trapping, focus restoration, and background `inert` | Added shared portal-based `Modal.tsx` with Escape close, Tab/Shift+Tab cycle trap, `inert` on `#root`, body scroll lock, focus restoration, and RTL story arrow navigation | Resolved |
| 6 | Shell Geometry & Font Scaling | Shell used `rem` units affected by root `15px * --font-scale` | Defined pixel shell tokens `--header-h: 56px`, `--bar-h: 64px`, `--tap: 44px` and bottom safe-area padding formula so shell stays stable at 150% text scale | Resolved |
| 7 | RTL Logical Properties | ChatBubble corners used physical `rounded-bl-sm`/`rounded-br-sm` | Switched to logical `rounded-es-sm`/`rounded-ee-sm` (`dir="rtl"` `lang="ar"` on `<html>`) | Resolved |
| 8 | External Image Fallback | Seed images hotlinked Unsplash and failed silently in `Avatar` | Generated local SVG assets under `/public/seed/`, added `SmartImage.tsx` placeholder/error fallback, and tracked image failure state in `Avatar.tsx` to render initials | Resolved |
