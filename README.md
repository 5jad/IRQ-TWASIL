# IRQ تواصل (Tawasul)

منصة اجتماعية وتجارية رقمية عراقية (نموذج واجهات أمامي تفاعلي مع بيانات تجريبية محلية - Frontend UI Prototype with Seed Data).

## نظرة عامة
تم بناء المشروع كنموذج أولي لواجهات المستخدم (PWA-first) بالاعتماد على:
- **React 19** و **Vite 8**
- **Tailwind CSS v4** بدعم كامل للاتجاه من اليمين لليسار (RTL-first)
- معايير الألوان والتباين (WCAG AA) لأربعة سمات (فاتح، داكن، هادئ، عالي التباين)
- خطوط محلية مدمجة (Cairo و Reem Kufi)

## التشغيل والتطوير
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# فحص الأنواع البرمجية (Lint)
npm run lint

# تشغيل اختبارات الوحدة وفحص التباين
npm test

# بناء حزمة الإنتاج
npm run build

# معاينة حزمة الإنتاج محلياً
npm run preview
```

## خريطة المجلدات (Folder Map)
```
/
├── public/                 # الأيقونات وملفات الخطوط وبيانات البذور الثابتة و manifest
├── scripts/                # سكربتات فحص التباين الآلية
├── src/
│   ├── components/
│   │   ├── chat/           # فقاعات المحادثة والموجات الصوتية
│   │   ├── feed/           # بطاقة المنشور وقصص المستخدمين
│   │   ├── gallery/        # معرض المكونات ونظام التصميم
│   │   ├── market/         # بطاقات السلع والمتجر
│   │   ├── modals/         # نوافذ الحوار والشيتات المنبثقة
│   │   ├── shell/          # الأشرطة الأساسية (TopBar, BottomBar, Sidebar, SideRail, RightPanel)
│   │   ├── ui/             # مكونات النظام الأساسية (الأزرار، الحقول، الشعار)
│   │   └── views/          # شاشات التطبيق الرئيسية
│   ├── context/            # حالة التطبيق والتفضيلات
│   ├── lib/                # دوال التنسيق، التحقق، وبيانات البذور
│   ├── types/              # تعريفات الأنواع في TypeScript
│   ├── App.tsx             # نقطة الدخول والموجه
│   ├── index.css           # توكنات التصميم والمتغيرات الأساسية
│   └── main.tsx            # نقطة التشغيل وتثبيت التطبيق
└── docs/                   # سجل القرارات الهندسية والمصادقة
```

## القيود الحالية (Limitations & Scope)
- التطبيق حالياً هو **واجهة مستخدم أمامية (Frontend-only Prototype)** تعتمد على بيانات بذور محلية داخلية (`seedData.ts`).
- لا يوجد خادم خلفي متصل (Backend)، ولا توجد قاعدة بيانات فعلية أو بوابات دفع حقيقية أو نظام بث فيديو مباشر فعلي (يتم محاكاتها محلياً للتجربة وتأكيد تفاعلات الواجهة).
